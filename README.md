# my portfolio
a silly and very basic portfolio about me and what I like. it has an 'about me' and 'projects' section.
live demo link: https://habiba0906.github.io/my-portfolio/

## key characteristics:
- a centered layout: fits different screens.
- soft colors: has a light pink background 'text-pink-100' paired with bold pink 'text-pink-600' heading and sky blue 'text-sky-600' for sections.

## sections:
Header: displays my name and current school.
About me: about my interests and who I am.
Projects: mentions solo projects I have worked on in the past.
  *featured projects:*
  -Helion: a solar flare detection project
  -Patterns Lab: an simple interactive website that explains concepts like Signal and Noise and Temporal memory.
Footer: closes the page with a simple goodbye and an image.

## Tech stack:
- html
- tailwind css

## Prerequisites:
any modern browser (chrome, edge, firefox, etc.)

## Running locally:
download index.html and open it using your browser.
